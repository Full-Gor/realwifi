# RealWiFi

Application mobile de sécurité WiFi qui analyse votre réseau pour détecter les menaces potentielles et les intrusions.

## Fonctionnalités

- **Scan du réseau WiFi** - Détection de tous les appareils connectés à votre réseau
- **Détection d'intrusions** - Identification des appareils non autorisés ou suspects
- **Analyse ARP Spoofing** - Détection des attaques man-in-the-middle
- **Vérification du chiffrement** - Analyse de la sécurité de votre connexion WiFi (WPA2/WPA3)
- **Historique des connexions** - Suivi des appareils qui se connectent à votre réseau
- **Alertes en temps réel** - Notifications instantanées en cas de menace détectée
- **Rapport de sécurité** - Score de sécurité et recommandations personnalisées

## Technologies

- React Native / Flutter
- Network scanning libraries
- SQLite pour le stockage local
- Push notifications

## Installation

```bash
# Cloner le repository
git clone https://github.com/Full-Gor/realwifi.git

# Installer les dépendances
cd realwifi
npm install

# Lancer l'application
npm start
```

## Permissions requises

- Accès WiFi
- Accès réseau local
- Notifications

## Avertissement

Cette application est destinée à un usage légal uniquement. Scannez uniquement les réseaux dont vous êtes propriétaire ou pour lesquels vous avez une autorisation explicite.
